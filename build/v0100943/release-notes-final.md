# 小美丽 V0.10.0.9.4.3

修复 TTS 与聊天后的资源释放，TTS 单次失败最多自动重试一次；综合测试沿用已有 ASR 进程，避免额外加载约 6GB 模型。白板图片、字体及 OCR 线程池也完成释放与复用修复。
