# 小美丽 V0.11.0.2｜透明 WebM + 更新桌面零落地

以正式 V0.11.0 为基线，完整包含 V0.11.0.1 的动作库透明 WebM Alpha 直读能力，并追加更新安全修正。

- 动作库全部 8 类素材池继续支持透明 WebM：带 Alpha 的 WebM 直接读取透明通道，不再二次抠绿。
- 普通 WebM、MP4、MOV、MKV、AVI、M4V 继续沿用原有绿幕导入流程。
- 若小美丽检测到 NDM 的更新下载目录是 Windows 桌面或桌面子目录，会在把下载 URL 发送给 NDM 之前停止本次更新。
- 不采用“更新完成后自动删除桌面 ZIP”的方案，因此不会删除、移动或覆盖桌面已有文件。
- 用户主动执行的一键深度资源测试、长时间交互诊断以及闪退诊断 ZIP 保留，不属于本次取消范围。
- 继续沿用 FullSafe：新版本安装到独立版本目录，旧版本保留，active_history 回滚记录保留，用户配置和素材不覆盖。
