# 小美丽 V0.11.0.3.1｜V0.11.0.3 桌面动作模板热修复

以正式 V0.11.0.3 为功能基线，完整保留桌面动作联动、透明 WebM、素材显示别名、NDM 桌面零落地、FullSafe、现有配置与全部素材。

- 修复桌面动作模板在“真实桌面测试 / 程序退出”时偶发 `libshiboken: Internal C++ object (DesktopTemplateDialog) already deleted` 的崩溃。
- 模板窗口改为持久引用 + Qt C++ 对象有效性检查；失效窗口只清引用，不再调用已销毁对象。
- 待机动画素材池单独扩展为 30 支；低血量、击杀、被击杀、获胜、失败、战报、桌面动作继续保持 20 支。
- 永久停用“启动时在桌面自动生成 小美丽.exe”的旧启动器机制；不会删除、移动、覆盖用户桌面上已经存在的任何文件。
- 继续保留诊断 ZIP 的主动导出功能；本次仅禁止程序自动在桌面创建 EXE。
- 更新过程继续使用 NDM 与受保护版本目录，保留旧版本和回滚，不递归清理任何用户目录。
