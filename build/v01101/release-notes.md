# 小美丽 V0.11.0.1｜动作库透明 WebM

基于正式 V0.11.0 安全追加更新。动作库全部 8 类视频现在都支持带 Alpha 的透明 WebM 直接导入。

透明 WebM 会直接读取 Alpha，不再经过绿幕取色、抠绿与去绿边，因此用户自己提前完成的抠像不会被二次处理。无 Alpha 的 WebM，以及 MP4 / MOV / MKV / AVI / M4V，继续使用原有绿幕导入链路。

导入后的透明素材仍使用现有透明动画 WebP 播放链、淡白描边/柔光、20 支素材池、桌面动作模板与游戏状态抢占机制。用户原始视频保持只读，不移动、不改名、不覆盖、不删除。

更新继续使用 FullSafe 新版本目录、版本并存与回滚机制，保留 NDM 优先下载。只有 Windows 构建、透明 Alpha 实测、冻结 EXE 自检、ZIP CRC/SHA-256 和公开下载回读全部通过后，才会切换 `latest_safe.json`。
