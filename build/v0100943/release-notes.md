# 小美丽 V0.10.0.9.4.3

基于正式 V0.10.0.9.4.2 和用户完整深度资源测试报告修复。

- TTS 由发起任务的线程统一释放音频、WebSocket、SDK 接收线程、回调和队列；一次失败最多自动重试一次。
- 聊天复用连接池，每次流式响应读取结束并关闭；暂时网络失败仅在尚未输出语音时重试一次，避免重复朗读。
- 综合资源测试复用已有 ASR 进程和模型，不再加载第二份约 6GB ASR。
- 修复白板字体重复注册、图片帧释放和重复转换任务。
- 为 OpenCV 和三个 OCR 模型会话明确限制线程池，检查首次 OCR 后的完整冷却与线程回落。

验收证据见 local-gates.json。发布候选包与本机实际测试 EXE 字节相同，公开包 SHA-256 回读完成后才开放更新。

自动资源验收在独立数据目录执行真实服务、模型和界面流程，仅该测试进程关闭外部输入法。日常程序保持用户原有输入法设置；输入法字典映射和外部组件线程不在这项自动验收范围内。原始失败及复测记录均保留。

资源诊断每次真实云端大脑请求采用临时 10 秒首字等待预算和 25 秒调用上限，不写入用户配置；日常聊天保留原有响应限时。网络请求真正失败仍会判验收失败，诊断不使用本地大脑回退。

旧版本、用户文件和当前安装均未删除、移动或覆盖。
