# 小美丽 V0.11.0.3｜桌面动作联动与模板修复

以正式 V0.11.0.2 为功能基线，完整保留透明 WebM、NDM 桌面零落地、FullSafe、全部配置与素材。

- 新增“爬出屏幕后接下一支动作”：第一支桌面动作完整爬出屏幕后，无闪回地接续指定动作。
- 新增“固定位置播放（视频内部自己动）”：适合“美蜘蛛”这类画面内已经自带悬挂/摆动运动的视频，整个桌宠窗口不再被额外平移。
- “下一支动作”明确只在“切换另一支桌面动作 / 爬出屏幕后接下一支动作”时生效，并使用下一支动作自己的模板位置与运动方式。
- 修复从“管理素材池”打开桌面动作模板时模板窗口被管理页压在下方的问题；子模板改为窗口模态并主动置前。
- 桌面动作模板改为屏幕自适应尺寸、滚动内容和两行位置参数布局，解决页面显示不完整、右侧参数被截断。
- 管理素材池支持右键“重命名”。为保证安全，仅保存显示别名，不修改原缓存文件名，不移动、不覆盖、更不删除任何用户文件。
- 保留 V0.11.0.2 的更新安全保护：NDM 更新目录若指向桌面或桌面子目录，会在任务提交前停止；不以“下载后删除 ZIP”的方式处理。
